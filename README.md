# Batch Video Generator

**Batch Video Generator** is an AI-powered video production tool built to create multiple connected video fragments in sequence, turning prompts into scalable batch generation workflows.

## What it does

- Creates video projects from one or multiple prompts
- Supports an optional reference image by upload or URL
- Generates sequential video expansions, where each new fragment continues from the previous output
- Processes multiple generations with configurable concurrency
- Supports aspect ratio, duration and resolution controls
- Includes project-level batch progress, logs and execution status
- Allows pause, resume and cancellation during processing
- Supports configurable API keys, models and timeout settings
- Uses real-time project and fragment updates

## Workflow

1. Create a video project
2. Add a reference image if needed
3. Define one or multiple video expansion prompts
4. Configure format, duration, resolution and concurrency
5. Start batch generation
6. Monitor progress and generated fragments in real time

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- Gemini / Veo API

## Concept

**Turn a sequence of creative prompts into an automated, controlled and scalable AI video generation pipeline.**
